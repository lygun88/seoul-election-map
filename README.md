# Seoul election map - mobile optimized

서울시 행정동별 1위 후보 득표율 지도입니다.

## 변경 사항
- 모바일에서 라벨이 겹치지 않도록 라벨 충돌 방지 적용
- 한강 및 주요 하천 오버레이를 은은한 보조선 스타일로 정리
- 행정구 경계선을 중복 없이 단일 레이어로 정리하고, 구명 라벨 톤을 낮춰 가독성 개선
- `동명+%`, `%만`, `라벨끄기`, `초기화` 버튼 추가
- 보이지 않는 동은 지도를 터치하면 하단 상세 패널에 표시
