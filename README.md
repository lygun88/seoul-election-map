# Seoul election map - mobile optimized

서울시 행정동별 1위 후보 득표율 지도입니다.

## 변경 사항
- 모바일에서 라벨이 겹치지 않도록 라벨 충돌 방지 적용
- 임의 좌표 하천선을 제거하고, 실제 행정동 GeoJSON의 강남·강북 구 경계 구간에서 한강 기준선을 추출
- 범례는 후보 2명만 표시하고 상단 보조 설명 문구 제거
- 행정구 내부 경계와 서울 외곽선을 분리해 더 깔끔한 선 스타일로 정리
- 구명 라벨 톤을 낮춰 행정동 색상과 득표율 라벨 가독성 개선
- `동명+%`, `%만`, `라벨끄기`, `초기화` 버튼 추가
- 보이지 않는 동은 지도를 터치하면 하단 상세 패널에 표시
